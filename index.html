Up and running in three steps

Once you have a server, linking takes minutes. No Meta approval or business account: you link the WhatsApp you already use, the same way as WhatsApp Web.

1

Scan the QR

Enter your phone number in your server's dashboard and scan the QR code from WhatsApp, under Linked devices.

2

Copy your keys

Your Client ID and Secret Key appear in the dashboard. Keep the Secret Key private.

3

Call the API

Send a POST /send request and the message leaves from your own WhatsApp number.

Authentication

Every API request needs your Client ID and Secret Key. Pass them as query parameters or as headers.

QueryHeader
clientidx-client-id
keyx-api-key

Headers keep your key out of server logs and browser history, so prefer them in production.

Send a message

POST/send
FieldWhereDetails
toquery or bodyNumber with country code, digits only (8801700000000). A full chat ID containing @ also works.
messageJSON bodyThe text to send.
curl -X POST "https://app.wpsent.xyz/send?to=8801700000000" \
  -H "x-client-id: cid_a1b2c3d4e5f6" \
  -H "x-api-key: YOUR_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"message":"Your order has shipped"}'

Response

{ "ok": true, "logId": "665f1c0e8a1b2c3d4e5f6a7b" }

GET/logs

Connection status

StatusMeaning
readyConnected. You can send messages.

disconnectedConnection dropped. It reconnects on its own.
auth_failureThe saved login is no longer valid. Use Rescan in the dashboard.
errorThe session failed to start. It retries automatically.
not_startedNo session is running for this number yet.

Webhooks

Add a webhook to get a call on your server whenever someone messages you. Manage them in the dashboard or with the API.

POST/webhooks
{ "url": "https://example.com/hook", "method": "POST", "label": "My app" }

method is POST (JSON body) or GET (query parameters). The URL must start with http:// or https://.

PATCH/webhooks/:id body: { "active": false } pauses it
DELETE/webhooks/:id

Both return { "ok": true, "webhooks": [...] } with your current list.

Incoming messages

Your webhook receives this payload for every message or reaction you get. Respond within 8 seconds.

{ "event": "message_received", "from": "8801700000000",
  "body": "Hi, is this still available?", "type": "text",
  "timestamp": "2026-01-01T10:00:00.000Z" }

type is one of text, image, video, audio, document, sticker, location, contact or reaction. Media arrives as a short label such as [Image], not the file itself.

Lost session or key

  • WhatsApp got disconnected: sign in with your Secret Key and press Rescan in the dashboard. Your Client ID and Secret Key stay the same, and the old saved session is cleared.
  • Forgot your Secret Key: choose Reset Secret Key on the sign-in page. We send a 6-digit code to your own WhatsApp chat, or ask for a QR scan if WhatsApp is not connected. Resetting creates a new Client ID and Secret Key and removes your webhooks.

Five wrong key attempts lock sign-in for 15 minutes.

Good to know

WPSent controls WhatsApp through WhatsApp Web. It is not the official WhatsApp Business API. Message people who expect to hear from you, because spam can get a number banned.
  • Keep your Secret Key on your server. Never put it in front-end code.
  • Rotating your key signs out every other session.
